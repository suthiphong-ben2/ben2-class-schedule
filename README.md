# ระบบตารางเรียน / ตารางสอบ โรงเรียนเบญจมราชรังสฤษฎิ์ ๒

หน้าเว็บอยู่บน GitHub Pages ข้อมูลเก็บใน Google Sheets ผ่าน Google Apps Script
(โครงสร้างเดียวกับระบบจองห้องประชุมและปฏิทินโรงเรียน)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าดูตาราง: ตารางเรียนรายห้อง, ตารางครู, การใช้ห้อง, หาครูว่าง/ห้องว่าง, ตารางสอบ |
| `admin.html` | หน้าผู้ดูแล: อัปโหลดไฟล์ T_ONE, ตารางสอบ, เวลาคาบ, ชื่อวิชา (ใช้รหัสผ่าน) |
| `tone-parser.js` | ตัวอ่านไฟล์ T_ONE (.XLS) ในเบราว์เซอร์ |
| `config.js` | ลิงก์ Web app ของ Apps Script (แก้ไฟล์นี้ไฟล์เดียว) |
| `apps-script/Code.gs` | โค้ดหลังบ้าน วางใน Apps Script ของ Google Sheet |
| `wordpress-embed.html` | โค้ดฝังหน้าตารางในเว็บ ben2.ac.th |

## ติดตั้ง (ครั้งแรกครั้งเดียว)

1. **สร้าง Google Sheet ใหม่** ตั้งชื่อเช่น `BEN2 ตารางเรียน`
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางโค้ดจาก `apps-script/Code.gs`
3. แก้บรรทัด `const ADMIN_PASSWORD = '...'` เป็นรหัสผ่านผู้ดูแล แล้วกดบันทึก
4. เลือกฟังก์ชัน **setup** แล้วกด **เรียกใช้** (ครั้งแรกจะขอสิทธิ์ ให้กดอนุญาต)
   ระบบจะสร้างชีต Timetable, Exams, Periods, Subjects ให้เอง
   หลังรันเสร็จ จะลบรหัสผ่านออกจากโค้ดก็ได้ ระบบเก็บไว้ใน Script Properties แล้ว
5. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   คัดลอกลิงก์ที่ลงท้ายด้วย `/exec`
6. เปิด `config.js` แล้ววางลิงก์นั้นแทนข้อความ `ใส่ลิงก์ Web app ของ Apps Script ที่นี่`
7. อัปโหลดทุกไฟล์ (ยกเว้นโฟลเดอร์ `apps-script` ไม่จำเป็น) ขึ้น repository บน GitHub
   แล้วเปิด **Settings → Pages → Deploy from a branch (main / root)**
8. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/admin.html` → เข้าสู่ระบบ → อัปโหลดไฟล์ T_ONE

## ใช้งานแต่ละเทอม

- **ตารางสอนใหม่:** หน้าแอดมิน → แท็บ "ตารางสอน (T_ONE)" → เลือกไฟล์ → ตรวจตัวเลขสรุป → บันทึก
- **ตารางสอบ:** เพิ่มทีละรายการ หรือกด "ดาวน์โหลดแม่แบบ" กรอกใน Excel แล้ว "นำเข้าจาก Excel"
  จะแก้ในชีต `Exams` ตรงๆ ก็ได้ (วันที่ใช้รูปแบบ `2027-02-22`) หน้าเว็บจะเห็นข้อมูลใหม่เอง
- **เวลาคาบ / ชื่อวิชา:** ตั้งครั้งเดียว ใช้ต่อได้ทุกเทอม รหัสวิชาใหม่จะขึ้นในแท็บ "ชื่อวิชา" ให้เติมชื่อ
  ไฟล์ `subjects-2-2569.xlsx` มีชื่อวิชา 257 วิชา (จากแบบแจ้งคาบสอน 2/2569 ของหัวหน้าหมวด)
  นำเข้าได้ที่แท็บ "ชื่อวิชา" → "นำเข้าจาก Excel" แล้วกดบันทึก

## ฝังในเว็บโรงเรียน

วางโค้ดจาก `wordpress-embed.html` ในบล็อก "HTML ที่กำหนดเอง" ของหน้า WordPress
(แก้ `src` เป็นลิงก์ GitHub Pages จริง) แนะนำให้ตั้งเทมเพลตหน้าเป็น **Elementor Full Width**

## เรื่องที่ควรรู้

- หน้าดูตารางเก็บข้อมูลไว้ในเบราว์เซอร์ และถาม Apps Script แค่ "เลขเวอร์ชัน" ก่อนทุกครั้ง
  จะโหลดข้อมูลเต็มเฉพาะเมื่อมีการเปลี่ยนแปลง ช่วยประหยัดโควตา Apps Script
- แก้โค้ด `Code.gs` แล้วต้องกด **การทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** ทุกครั้ง ลิงก์ `/exec` จะคงเดิม
- เปลี่ยนรหัสผ่าน: แก้ `ADMIN_PASSWORD` ในโค้ด แล้วรัน `setup` อีกครั้ง (ข้อมูลเดิมไม่หาย)
